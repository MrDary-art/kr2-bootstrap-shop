# AquaWave Park

Коммерческий сайт семейного аквапарка AquaWave Park. Сайт знакомит гостей с зонами отдыха, волновым бассейном, кафе и помогает оставить заявку на подбор билетов.

## Страницы

- `index.html` — главная страница;
- `catalog.html` — зоны и развлечения;
- `product.html` — волновой бассейн;
- `cafe.html` — кафе и питание;
- `order.html` — заявка на подбор билетов.

## Технологии

- HTML5;
- Bootstrap 5;
- CSS3;
- JavaScript.

## Медиа

Визуалы сайта хранятся локально в `assets/images/`, поэтому страницы не зависят от случайных внешних изображений.
