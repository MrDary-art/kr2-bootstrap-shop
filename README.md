# Контрольная работа №2 — AquaWave

## Описание

AquaWave — учебный сайт семейного аквапарка с горками, бассейнами и зонами
отдыха. На главной странице посетитель знакомится с возможностями аквапарка и
популярными зонами.

## Практическая работа №9

Реализована стартовая страница КР №2 на Bootstrap-сетке:

- Bootstrap 5.3.3 подключён через CDN;
- подключён собственный файл `css/custom.css`;
- созданы шапка и адаптивная Bootstrap-навигация;
- добавлен полноширинный hero-блок на основе `container-fluid`, `container`, `row` и `col-*`;
- создан блок преимуществ;
- создана адаптивная сетка популярных зон через
  `col-12 col-md-6 col-lg-4`;
- добавлен подвал;
- подключён Bootstrap JS Bundle для раскрывающегося меню.

## Практическая работа №10

Проект расширен готовыми Bootstrap-компонентами:

- созданы страницы `catalog.html`, `product.html` и `order.html`;
- единая адаптивная навигация добавлена на все четыре страницы;
- каталог использует компоненты `card`, `badge`, `btn` и `alert`;
- добавлено модальное окно быстрой заявки `modal`;
- форма заявки использует `form-control`, `form-select`, `input-group` и `form-check`;
- на странице заявки добавлен компонент `accordion` с FAQ;
- добавлен `js/main.js` для учебного сообщения об успешной отправке формы.

## Запуск

Откройте файл `index.html` в браузере. Для корректной загрузки Bootstrap через
CDN требуется подключение к интернету.

## Использованные иллюстрации

В макете используются атмосферные фотографии воды из сервиса Picsum Photos.
Они иллюстрируют тему воды и не изображают реальный аквапарк AquaWave.
